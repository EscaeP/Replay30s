# 回录30秒

回录30秒是一款 Android 屏幕回放工具。

先开启缓存。需要保留刚刚发生的画面时，点击保存。应用会保存最近约 30 秒的视频。

## 安装

测试安装包在：

`app/build/outputs/apk/debug/app-debug.apk`

将 APK 传到手机后打开。按系统提示允许安装。

## 使用方法

1. 打开“回录30秒”。
2. 阅读免责声明，点击“我已知晓”。
3. 点击“开始缓存”。
4. 按系统提示允许通知、播放声音和屏幕录制权限。
5. 缓存开始后，圆形计时器会显示可保存秒数，最多 30 秒。
6. 使用以下任一方法保存回放：
   - 点击应用中的“保存回放”。
   - 点击悬浮按钮。
   - 点击下拉控制中心的“回录30秒”快捷开关。
7. 视频保存到系统媒体库的 `Movies/Replay30`。

保存回放不会停止缓存。可以继续保存下一段视频。

## 悬浮按钮

在“悬浮按钮”开关中开启此功能，并允许系统悬浮窗权限。

- 按钮会在缓存开始后显示。
- 单击按钮会保存回放。
- 按钮会停靠到屏幕边缘。
- 保存后按钮仍保留，缓存继续运行。

## 暂停缓存

点击“暂停缓存”后，应用停止采集屏幕画面，但保留当前缓存。此时仍可保存回放。

再次点击“开始缓存”会清理旧缓存并开始新的录制。关闭应用也会清理未保存缓存。

## 声音

应用尝试录制允许 Android 捕获的应用播放声音。

应用不录制麦克风声音。通话、受保护媒体和禁止声音捕获的应用可能无声。

## 控制中心快捷开关

在“系统快捷方式”中添加“回录30秒”。

- 未开始缓存时，点击快捷开关会打开应用和录屏授权。
- 正在缓存或暂停时，点击快捷开关会保存回放。
- 如果系统不能自动添加，按弹窗说明在控制中心编辑页手动添加。

## 注意事项

- 只能保存开启缓存之后的内容。
- 屏幕熄灭时，缓存停止并清理。
- 受系统保护的页面可能显示黑屏。
- 原始屏幕分辨率优先。如果编码器不支持，应用会自动选择兼容分辨率。
- 长时间录制会增加耗电和发热。
- 请遵守当地法律、平台规则和他人隐私权。

## 构建

需要 JDK 17 和 Android SDK API 35。

在项目根目录运行：

```powershell
.\gradlew.bat assembleDebug
```

生成的 APK 位于：

`app/build/outputs/apk/debug/app-debug.apk`
