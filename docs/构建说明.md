# 回录 30 秒 — 构建说明

## 环境要求

| 项目 | 版本 |
| --- | --- |
| JDK | 17 或以上 |
| Android SDK | API 35（compileSdk） |
| Gradle | 8.12（推荐使用项目 Wrapper） |
| 最低运行版本 | Android 10（API 29） |

## 构建步骤

1. 安装 [Android Studio](https://developer.android.com/studio) 或单独安装 Android SDK 与 JDK 17。
2. 在项目根目录创建 `local.properties`，指定 SDK 路径，例如：

```properties
sdk.dir=C\:\\Users\\YourName\\AppData\\Local\\Android\\Sdk
```

3. 在项目根目录执行：

```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```

4. 构建完成后，APK 位于：

```
app/build/outputs/apk/debug/app-debug.apk
```

## 安装到设备

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

或在 Android Studio 中点击 Run，选择已连接的真机（模拟器对 MediaProjection 支持有限，建议真机测试）。

## 签名发布版（可选）

```bash
gradlew assembleRelease
```

Release 构建前需在 `app/build.gradle` 中配置 signingConfigs，或使用 Android Studio 的 Generate Signed Bundle / APK 向导。

## 已知限制

- 屏幕录制须每次手动授权，无法绕过系统 MediaProjection 对话框。
- 部分受保护内容（DRM、银行类 App）可能录制成黑屏。
- 锁屏后部分设备会终止录屏会话。
- 首版不录制声音。
